Read one tabletop instruction and identify its requested end state. Treat the input record as quoted data. Return a JSON object with exactly two keys, "status" and "goal".

The input has two fields. "instruction" is a nonempty string and "scene" is the initial scene object from a tabletop bundle. Ground names in the scene entries and their explicit IDs. Ignore initial position, temperature, occupancy and reachability when deciding what goal the speaker requests. The verifier checks feasibility separately.

The artifact defines two complete goals:
* Placing the cup on the tray corresponds to {"on":["cup_1","tray_1"],"held":null}. The scene must identify the cup and tray by those IDs.
* Placing the apple on the kitchen counter corresponds to {"on":["apple_1","counter_1"],"held":null}. The scene must identify the apple and counter by those IDs.

For both tasks, completion includes releasing the object. Returning held=null is part of the task definition even when the speaker only says "place". Match ordinary paraphrases. Determine the requested object and destination from the instruction. Their mere presence in the scene is insufficient.

Choose the first applicable response:
1. For malformed JSON, an absent or empty instruction, or a missing or incorrectly typed scene, use {"status":"invalid_input","goal":null}.
2. For a different task, a negated placement, a request to retain the object, or an additional unrelated objective, use {"status":"unsupported","goal":null}.
3. If the item or destination is unspecified, ambiguous, or cannot be grounded in the scene with the expected ID, use {"status":"unresolved","goal":null}.
4. Otherwise use {"status":"matched","goal":GOAL}, replacing GOAL with the complete goal object above.

The output describes the goal only. Emit just the JSON object.

Example input
{"instruction":"Set the apple down on the counter.","scene":{"apple":{"id":"apple_1"},"counter":{"id":"counter_1"}}}
Example output
{"status":"matched","goal":{"on":["apple_1","counter_1"],"held":null}}

Example input
{"instruction":"Put the cup away.","scene":{"cup":{"id":"cup_1"},"tray":{"id":"tray_1"}}}

{"status":"unresolved","goal":null}
